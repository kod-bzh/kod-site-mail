# Kod BZH — identité visuelle

Logos PNG et polices New Amsterdam fournis par Igor dans `Kod Bzh.zip`, le 26 octobre 2026. Les logos sont conservés sans retouche.

Charte appliquée dans `src/app/globals.css` : bleu `#1612d3`, encre `#1a1a1a`, crème `#f5f4ef`, papier `#fbfaf6`.

Les polices sont servies localement via `next/font/local` :
- New Amsterdam : archive fournie, titres uniquement.
- Open Sauce Sans : projet [Open Sauce Fonts](https://github.com/marcologous/Open-Sauce-Fonts) (regular) et Fontsource (500, 600, 700).
- IBM Plex Mono : Fontsource (400, 500).

Les licences des polices complémentaires sont dans `fonts/`.
